# Canopy attachment registration

The original source, clean background and assembled Unity capture showed three independent errors: the generated roof edge sagged below the original front attachment curve, the front extraction clipped the original seam, and the rear extraction omitted the attachment folds.

`HauntedMerchantOriginalOverhang.json` traces the original front edge and includes the rear attachment strips. Extraction preserves original source coordinates and RGB. The derived extraction and mask are saved assets.

`HauntedMerchantRoofRegistration.json` records matching source and destination roof-edge anchors. The clean roof was registered locally, keeping the trees, knot, support beam and lower scene fixed. It changes only pixels on the roof side of the target edge; the band narrows toward the right tie and stops at x610. This is a static authored image, not runtime deformation. The registration neither repaints nor repositions the hanging fabric.

The installed background is `MerchantRegisteredRoofPlate.png`, native 941 x 1672. Its byte-identical authoring reference is `HauntedMerchantRegisteredRoofPlate.png`. SHA256: `6E0BAE1D89041D6158BE5EF5A7E22C36DC1B71A672DA020200C06B5B1AE5290F`. Compared with the clean source, 27,029 pixels change within x126..609, y1..276; none change outside the roof area. The corrected cloth selection contains 70,564 pixels.
